# Alias de fonction

`proc_benchmarking()` est un alias de
[`benchmarking()`](https://StatCan.github.io/gensol-gseries/fr/reference/benchmarking.md)

`proc_tsraking()` est un alias de
[`tsraking()`](https://StatCan.github.io/gensol-gseries/fr/reference/tsraking.md)

`macro_gseriestsbalancing()` est un alias de
[`tsbalancing()`](https://StatCan.github.io/gensol-gseries/fr/reference/tsbalancing.md)

## Utilisation

``` r
proc_benchmarking(...)

proc_tsraking(...)

macro_gseriestsbalancing(...)
```

## Arguments

- ...:

  Arguments de la fonction correspondante.

## Valeur de retour

Voir la fonction correspondante :

- [`benchmarking()`](https://StatCan.github.io/gensol-gseries/fr/reference/benchmarking.md)
  pour l'alias `proc_benchmarking()`

- [`tsraking()`](https://StatCan.github.io/gensol-gseries/fr/reference/tsraking.md)
  pour l'alias `proc_tsraking()`

- [`tsbalancing()`](https://StatCan.github.io/gensol-gseries/fr/reference/tsbalancing.md)
  pour l'alias `macro_gseriestsbalancing()`

## Détails

Le nom de ces alias rappelle l'origine SAS\\^\circledR\\ de la fonction
correspondante (PROC BENCHMARKING, PROC TSRAKING et macro
***GSeriesTSBalancing*** dans G-Séries 2.0). Ces alias assurent
également la compatibilité avec les premières versions de développement
de la librairie R.

Voir la fonction correspondante pour plus de détails, y compris des
exemples complets, une description détaillée des arguments et la valeur
de retour.
