# gseries: Improve the Coherence of Your Time Series Data

'R' version of 'G-Series', Statistics Canada's generalized system
devoted to the benchmarking and reconciliation of time series data. The
methods used in 'G-Series' essentially come from Dagum, E. B., and P.
Cholette (2006)
[doi:10.1007/0-387-35439-5](https://doi.org/10.1007/0-387-35439-5) .
